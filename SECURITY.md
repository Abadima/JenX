# Security Policy

I take security seriously. If you find a vulnerability in JenX, please report it privately so I can investigate and address it.

## Supported Versions

I currently provide security updates for the latest maintained release.

| Version        | Supported    |
| -------------- | ------------ |
| Latest release | Yes          |
| Older releases | No guarantee |

## Reporting a Vulnerability

Please use [GitHub Private Vulnerability Reporting](../../security/advisories/new).

**Please don't report security vulnerabilities through public Issues, Discussions, or pull requests.**

When submitting a report, include as much detail as possible:

- What you found and what it could affect.
- Steps to reproduce the issue.
- The affected version or component.
- Relevant logs, screenshots, or proof of concept.
- Any suggested fixes, if you have them.

Please avoid including other users' personal information, credentials, or access tokens.

## Scope

I'm interested in reports involving JenX and software maintained as part of this project, particularly:

- Authentication and permission issues.
- Exposure of credentials, tokens, or sensitive data.
- Injection and remote code execution.
- Discord command, event, and interaction handling.
- Unauthorized access to server or user data.
- Denial of service and resource exhaustion.
- Vulnerable dependencies that affect JenX.
- Unsafe handling of external services and user input.

Vulnerabilities in Discord, AnimeX, or other third-party platforms are outside the scope of this policy. Issues in JenX's own integrations with those services are still in scope.

Please don't test against third-party infrastructure or systems you don't have permission to assess.

## Responsible Disclosure

Please give me a reasonable opportunity to investigate and fix a vulnerability before disclosing it publicly.

Keep reports private, avoid accessing other users' data, and don't disrupt services or go beyond what's necessary to demonstrate the issue.

I'll make a reasonable effort to investigate valid reports, although response and resolution times will depend on the severity and complexity of the issue.

## Acknowledgements

I'm happy to credit people who responsibly report vulnerabilities, provided they're comfortable being acknowledged publicly.

## Safe Harbor

I welcome good-faith security research conducted within the scope of this policy. I don't intend to pursue legal action solely because someone conducts research responsibly and follows these guidelines.

This doesn't grant permission to access systems or data you aren't authorized to access, or to test third-party services such as Discord and AnimeX.

---

Thanks to everyone who takes the time to help keep JenX secure.
