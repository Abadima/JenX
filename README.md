# JenX

**A Discord bot connecting the AnimeX and Jena ecosystems.**

JenX is a community-focused Discord bot developed for the Jena ecosystem. It is designed to make interacting with AnimeX and the wider Jena ecosystem more convenient through lightweight Discord functionality and contextual assistance.

The project prioritizes simplicity, reliability, and maintainability, while leaving room for future integrations and features.

## Features

- **AnimeX link assistant:** Recognizes relevant messages and helps users find AnimeX pages, including its homepage, catalog, schedule, and community.
- **Discord integration:** Provides lightweight bot functionality through Discord commands and events.
- **Channel-aware responses:** Uses a per-channel cooldown to avoid repetitive or simultaneous automated replies.

## Privacy and Data Handling

JenX currently processes relevant Discord messages in memory to identify requests and provide responses.

The current application logic does not intentionally persist message content or user data in a database. However, JenX may operate across both self-managed infrastructure and third-party hosting providers. Those providers may process operational information, such as connection metadata or server logs, under their own policies.

Future features involving account linking, external APIs, or persistent data may introduce additional data-processing requirements. Any such changes should be documented as the project evolves.
